Test software download

Every build we want anyone to touch is published to the GitHub releases page — the native clients (desktop, TUI, Android), the CLI, and the .deb packages for running your own relay or node:

github.com/bitworker20/bitpoker/releases/latest

/latest always redirects to the newest tagged release, so this link never goes stale. Packages install software, not state: they never touch genesis files, keys or keyrings, and nothing starts on install — see Operations for what a package does and does not do to a host.

Play online

The browser client runs the same gamecore the native clients do, compiled to WASM, and connects to the same relay and chain:

app.bitpk.top

No install: open the page, fund a seat with test chips, and you are matched against whoever else is waiting. The browser key sits in the page, which is why this path is testnet-only — the threat model is documented, and there is no mainnet for it to lose real money on.

Block explorer

Every intent, match, settlement and dispute lands on chain and is visible here — the fastest way to see the escrow lifecycle a hand actually walks through:

explorer.bitpk.top

Useful things to look for: OpenGameIntent matching into a session, the escrow lock and release around each hand, and — if you abandon a session mid-play — the evidence → DISPUTED → adjudication trail with the engine's verdict and the payout split.

Getting test chips

Test chips (UCHIP) come from the faucet, behind the same invitation code that opens this site: redeem a code and the grant rides with it. Codes are issued by hand, counted, and can be revoked — the faucet enforces per-wallet, per-IP and daily budget limits, so a leaked code drains a capped amount, not a treasury.

Chips have no monetary value. This is a test network: the software is real, the cryptography is real, the money is not. Do not treat any address on it as one you would reuse elsewhere.

Service endpoints live in config.js (faucet API, explorer, webapp) so an operator can repoint a deployment in one place. Faucet operations: docs/faucet/README.md.
